Bridge SIPP Training
Welcome to the Bridge SIPP Training repository — a curated collection of Java practice programs structured by topic and day. This training material is designed to guide learners from foundational programming concepts to more advanced object-oriented techniques through hands-on problem solving.

Folder Structure & Highlights
🔹 Day 1: Practice Problems
Entry-level exercises to get started with Java

Focus on arithmetic operations, basic conversions, and geometric calculations

Ideal for reinforcing core programming logic and syntax

🔹 Day 2: Java Fundamentals
Covers the building blocks of Java programming

Includes arithmetic logic, type casting, unit conversion, and swapping techniques

Establishes a solid grasp of basic Java syntax and structure

🔹 Day 3: Control Flows
Emphasis on if-else, for, and while loops

Includes programs for number theory (Armstrong, Prime, Harshad, etc.)

Practical logic-building through factorials, voting eligibility, leap years, and more

🔹 Day 4: Arrays
Comprehensive practice with one-dimensional and two-dimensional arrays

Tasks include array transformations, FizzBuzz, grade processing, and digit analysis

Sharpens problem-solving skills with array manipulation techniques

🔹 Day 5: Strings
Deep dive into string operations and manipulation

Includes case changes, substring extraction, and comparison logic

Also covers word counting, vowel/consonant identification, and exception handling

🔹 Day 6: Methods
Focuses on modular programming using static methods

Exercises include calculations in trigonometry, interest, unit conversions, and more

Helps learners break problems into manageable, reusable components

🔹 Day 7: Classes & Objects
Introduces core object-oriented programming principles

Projects based on real-life examples (Employee, Student, BankAccount, MovieTicket, etc.)

Builds understanding of encapsulation, constructors, and object interaction
